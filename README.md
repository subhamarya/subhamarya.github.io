# Subham Arya Portfolio

Static resume-backed portfolio site for Subham Arya.

## Files

- `index.html` - one-page portfolio
- `styles.css` - responsive visual design
- `script.js` - small header and footer behavior
- `assets/Subham_Arya.pdf` - source resume PDF linked from the site

## Publish

This site is ready for GitHub Pages. Push the repository to GitHub, then enable Pages from the repository settings using the root directory as the publishing source.
